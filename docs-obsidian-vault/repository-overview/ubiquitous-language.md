# ユビキタス言語

プロダクトドメインで使う用語を、日本語・英語・意味のセットで管理する。
適宜追記し、コード上とドキュメント上での表記揺れを防ぐ。

## 用語

### 制作者 / Author

ポートフォリオの制作主体であり、本サイトで公開される制作物・スキル・自己紹介の持ち主。
本リポジトリの文脈では sukuname4976 (リポジトリ所有者本人) ただ一人を指す。

### ユーザー / User

ポートフォリオサイトを閲覧し、提供されているサービスを利用する主体。

### ポートフォリオ / Portfolio

自己紹介・制作物・スキルを閲覧可能にするアプリケーション。
当アプリケーションは sukuname4976 のポートフォリオである。

### プレーリーカード / Prairie Card

初対面の相手に自己紹介を共有する外部サービス。
本アプリはプレーリーカードからの遷移を主要な配布導線として想定する。
